## 二、安装 Python 虚拟环境

### 2.1 安装 Python 3.11+

**方案 A：使用源码编译（推荐，兼容性最好）**

```bash
# 安装编译依赖
# CentOS
yum install -y openssl-devel bzip2-devel libffi-devel readline-devel sqlite-devel

# Ubuntu
apt install -y libssl-dev libbz2-dev libffi-dev libreadline-dev libsqlite3-dev

# 下载 Python 3.11
cd /opt
wget https://www.python.org/ftp/python/3.11.9/Python-3.11.9.tgz
tar -xzf Python-3.11.9.tgz
cd Python-3.11.9

# 编译安装
./configure --enable-optimizations --prefix=/usr/local/python3.11
make -j$(nproc)
make install

# 创建软链接
ln -sf /usr/local/python3.11/bin/python3.11 /usr/local/bin/python3
ln -sf /usr/local/python3.11/bin/pip3.11 /usr/local/bin/pip3

# 验证
python3 --version
# 输出: Python 3.11.9
```

**方案 B：使用 pyenv（多版本管理更灵活）**

```bash
# 安装 pyenv
curl https://pyenv.run | bash

# 将以下内容追加到 ~/.bashrc
echo 'export PATH="$HOME/.pyenv/bin:$PATH"' >> ~/.bashrc
echo 'eval "$(pyenv init -)"' >> ~/.bashrc
echo 'eval "$(pyenv virtualenv-init -)"' >> ~/.bashrc
source ~/.bashrc

# 安装 Python 3.11
pyenv install 3.11.9
pyenv global 3.11.9

# 验证
python --version
```

### 2.2 创建项目虚拟环境

```bash
# 进入项目目录
cd /var/www/myweb/backend

# 使用 venv 创建虚拟环境
/usr/local/bin/python3 -m venv venv

# 激活虚拟环境
source venv/bin/activate

# 验证虚拟环境
```


## 四、安装与配置 PostgreSQL

### 4.1 安装 PostgreSQL 15+

**CentOS：**

```bash
# 安装 PostgreSQL 官方仓库
yum install -y https://download.postgresql.org/pub/repos/yum/reporpms/EL-7-x86_64/pgdg-redhat-repo-latest.noarch.rpm
yum install -y postgresql15-server postgresql15-contrib

# 初始化数据库
/usr/pgsql-15/bin/postgresql-15-setup initdb

# 启动并设置开机自启
systemctl enable postgresql-15
systemctl start postgresql-15
```

**Ubuntu：**

```bash
# 安装 PostgreSQL
apt install -y postgresql postgresql-contrib

# 启动并设置开机自启
systemctl enable postgresql
systemctl start postgresql
```

### 4.2 配置 PostgreSQL

```bash
# 切换到 postgres 用户
sudo -u postgres psql

# 创建数据库
CREATE DATABASE myweb;
CREATE DATABASE myweb_test;

# 创建专用用户
CREATE USER myweb_user WITH PASSWORD 'your-strong-password-here';

# 授予权限
GRANT ALL PRIVILEGES ON DATABASE myweb TO myweb_user;
GRANT ALL PRIVILEGES ON DATABASE myweb_test TO myweb_user;

# 退出
\q
```

### 4.3 配置远程访问（按需）

```bash
# 编辑 pg_hba.conf
# CentOS: /var/lib/pgsql/15/data/pg_hba.conf
# Ubuntu: /etc/postgresql/15/main/pg_hba.conf

# 添加以下行以允许密码认证
# 在文件末尾添加：
host    myweb           myweb_user      0.0.0.0/0               md5

# 修改 postgresql.conf，监听所有地址
# 找到 listen_addresses 行，修改为：
listen_addresses = '*'

# 重启 PostgreSQL
systemctl restart postgresql-15  # CentOS
systemctl restart postgresql     # Ubuntu
```

### 4.4 安全建议

```bash
# 建议使用本地 socket 连接，不开放远程端口
# 确保阿里云安全组仅开放必要端口（见 8.3 节）

# 生产环境强烈建议：
# 1. 数据库与应用同机部署时使用 Unix Socket
# 2. 不同机部署时使用内网 IP + SSL/TLS
```

## 七、使用 systemd 管理应用进程

### 7.1 创建 systemd 服务单元

```bash
sudo vim /etc/systemd/system/myweb-api.service
```

写入以下内容：

```ini
[Unit]
Description=MyWeb FastAPI Application
After=network.target postgresql.service redis.service
Wants=postgresql.service redis.service

[Service]
Type=simple
User=www-data
Group=www-data
WorkingDirectory=/var/www/myweb/backend

# 虚拟环境路径
Environment=PATH=/var/www/myweb/backend/venv/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin
Environment=PYTHONPATH=/var/www/myweb/backend
Environment=APP_ENV=prod

# 加载 .env.production 环境变量
EnvironmentFile=/var/www/myweb/backend/.env.production

# Gunicorn + Uvicorn 启动命令
ExecStart=/var/www/myweb/backend/venv/bin/uvicorn main:app \
    --host 127.0.0.1 \
    --port 8000 \
    --workers 4 \
    --loop uvloop \
    --http httptools \
    --log-level info \
    --access-log \
    --log-config /var/www/myweb/backend/logging.conf

# 进程管理
Restart=always
RestartSec=5
StartLimitInterval=0
StartLimitBurst=5

# 文件描述符限制
LimitNOFILE=65536

# 安全设置
NoNewPrivileges=true
ProtectSystem=full
ProtectHome=true
PrivateTmp=true

[Install]
WantedBy=multi-user.target
```

### 7.2 创建日志配置文件（可选）

```bash
vim /var/www/myweb/backend/logging.conf
```

```ini
[loggers]
keys=root,uvicorn

[handlers]
keys=console,file

[formatters]
keys=default

[logger_root]
level=INFO
handlers=console,file

[logger_uvicorn]
level=INFO
handlers=console,file
qualname=uvicorn
propagate=0

[handler_console]
class=StreamHandler
level=INFO
formatter=default
args=(sys.stderr,)

[handler_file]
class=handlers.RotatingFileHandler
level=INFO
formatter=default
args=('/var/www/myweb/backend/logs/api.log', 'a', 10485760, 10)

[formatter_default]
format=%(asctime)s - %(name)s - %(levelname)s - %(message)s
datefmt=%Y-%m-%d %H:%M:%S
```

### 7.3 启动服务

```bash
# 重新加载 systemd
sudo systemctl daemon-reload

# 设置日志目录权限
sudo mkdir -p /var/www/myweb/backend/logs
sudo chown -R www-data:www-data /var/www/myweb/backend/logs
sudo chown -R www-data:www-data /var/www/myweb/backend/uploads

# 启动服务
sudo systemctl enable myweb-api
sudo systemctl start myweb-api

# 查看状态
sudo systemctl status myweb-api

# 查看日志
sudo journalctl -u myweb-api -f
```

## 八、配置 Nginx 反向代理

### 8.1 安装 Nginx

```bash

systemctl enable nginx
systemctl start nginx

# Ubuntu
apt install -y nginx
```

### 8.2 创建 Nginx 配置文件

```bash
vim /etc/nginx/conf.d/myweb.conf
```

```nginx
# HTTP → HTTPS 重定向
server {
    listen 80;
    server_name your-domain.com www.your-domain.com;
    return 301 https://$server_name$request_uri;
}

# HTTPS 配置
server {
    listen 443 ssl http2;
    server_name your-domain.com www.your-domain.com;

    # SSL 证书（使用阿里云免费证书或 Let's Encrypt）
    ssl_certificate     /etc/nginx/ssl/your-domain.com/fullchain.pem;
    ssl_certificate_key /etc/nginx/ssl/your-domain.com/privkey.pem;
    ssl_protocols       TLSv1.2 TLSv1.3;
    ssl_ciphers         HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;
    ssl_session_cache   shared:SSL:10m;
    ssl_session_timeout 10m;

    # 安全头
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;
    add_header Referrer-Policy "strict-origin-when-cross-origin" always;

    # 客户端上传大小限制（匹配 MAX_UPLOAD_SIZE）
    client_max_body_size 10M;

    # Gzip 压缩
    gzip on;
    gzip_types application/json text/plain text/css application/javascript;
    gzip_min_length 1024;

    # API 反向代理
    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # 透传原始请求 ID（如已有）
        proxy_set_header X-Request-ID $request_id;

        # 超时设置
        proxy_connect_timeout 60s;
        proxy_read_timeout 60s;
        proxy_send_timeout 60s;

        # 缓冲
        proxy_buffering off;
    }

    # Admin 后台（可选，可与 API 共用）
    location /admin/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # 健康检查端点
    location /health {
        proxy_pass http://127.0.0.1:8000/health;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        access_log off;
    }

    # OpenAPI 文档
    location /docs {
        proxy_pass http://127.0.0.1:8000/docs;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location /openapi.json {
        proxy_pass http://127.0.0.1:8000/openapi.json;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # 静态文件（上传目录）
    location /uploads/ {
        alias /var/www/myweb/backend/uploads/;
        expires 7d;
        add_header Cache-Control "public, immutable";
        access_log off;
    }

    # 拒绝访问敏感文件
    location ~ /\.env {
        deny all;
        access_log off;
        log_not_found off;
    }

    location ~ /\.git {
        deny all;
        access_log off;
        log_not_found off;
    }

    # 日志
    access_log /var/log/nginx/myweb-access.log;
    error_log  /var/log/nginx/myweb-error.log;
}
```

### 8.3 配置 SSL 证书

**方案 A：阿里云免费 SSL 证书**

1. 登录阿里云控制台 → SSL 证书 → 免费证书
2. 申请证书，验证域名所有权
3. 下载 Nginx 版证书，上传到服务器：

```bash
# 创建证书目录
mkdir -p /etc/nginx/ssl/your-domain.com

# 上传证书文件（在本地执行）
scp your-cert.pem root@服务器IP:/etc/nginx/ssl/your-domain.com/fullchain.pem
scp your-key.pem root@服务器IP:/etc/nginx/ssl/your-domain.com/privkey.pem
```

**方案 B：Let's Encrypt（免费自动续期）**

```bash
# 安装 certbot
# CentOS
yum install -y certbot python3-certbot-nginx

# Ubuntu
apt install -y certbot python3-certbot-nginx

# 获取证书（会自动修改 Nginx 配置）
certbot --nginx -d your-domain.com -d www.your-domain.com

# 测试自动续期
certbot renew --dry-run
```

### 8.5 阿里云安全组配置

在阿里云 ECS 控制台 → 安全组 → 配置规则，开放以下端口：

| 端口 | 协议 | 用途 | 源 |
|------|------|------|----|
| 22 | TCP | SSH | 你的办公 IP（推荐）|
| 80 | TCP | HTTP | 0.0.0.0/0 |
| 443 | TCP | HTTPS | 0.0.0.0/0 |
| 5432 | TCP | PostgreSQL | 不开放（仅内网）|
| 6379 | TCP | Redis | 不开放（仅内网）|

```python
# 创建初始管理员用户
import asyncio
from sqlalchemy import select
from core.database import async_session_factory
from apps.users.models import User
from apps.users.services import hash_password

async def create_admin():
    async with async_session_factory() as db:
        # 检查是否已存在
        stmt = select(User).where(User.username == "admin")
        result = await db.execute(stmt)
        if result.scalar_one_or_none():
            print("管理员用户已存在，跳过")
            return

        admin = User(
            username="admin",
```

```bash
redis-cli -a "你的密码" config get requirepass

```

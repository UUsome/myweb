## 四、数据库配置（SQLite / MySQL / PostgreSQL）

### 4.1 SQLite（本地开发默认，零配置）

项目默认使用 SQLite，**无需安装任何数据库服务**，开箱即用。

`.env` 中的默认配置：

```ini
DATABASE_URL=sqlite+aiosqlite:///./myweb.db
```

数据库文件会自动创建在 `backend/myweb.db`，开发调试非常方便。

> **💡 注意**：SQLite 不支持并发写入，仅适用于本地开发。多人协作或生产环境请切换为 MySQL / PostgreSQL。

### 4.2 切换为 PostgreSQL（生产环境）

```powershell
# 1. 安装 PostgreSQL
# 前往 https://www.postgresql.org/download/windows/ 下载安装
# 设置密码为 postgres

# 2. 启动服务
Start-Service postgresql-x64-15

# 3. 创建数据库
& "C:\Program Files\PostgreSQL\15\bin\psql.exe" -U postgres -c "CREATE DATABASE myweb;"

# 4. 安装 asyncpg 驱动
pip install asyncpg

# 5. 修改 .env 文件
# DATABASE_URL=postgresql+asyncpg://postgres:postgres@localhost:5432/myweb
```

### 4.3 切换为 MySQL（生产环境）

```powershell
# 1. 安装 MySQL（前往 https://dev.mysql.com/downloads/installer/ 下载）

# 2. 创建数据库
mysql -u root -p -e "CREATE DATABASE myweb CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# 3. 安装 aiomysql 驱动
pip install aiomysql

# 4. 修改 .env 文件
# DATABASE_URL=mysql+aiomysql://root:password@localhost:3306/myweb
```

### 4.4 数据库驱动速查

| 数据库 | DATABASE_URL 格式 | 需要安装的驱动 |
|--------|-------------------|---------------|
| SQLite | `sqlite+aiosqlite:///./myweb.db` | `aiosqlite`（已内置） |
| PostgreSQL | `postgresql+asyncpg://user:pass@host/db` | `pip install asyncpg` |
| MySQL | `mysql+aiomysql://user:pass@host/db` | `pip install aiomysql` |

## 五、Redis（可选，本地开发用内存替代）

**本地开发默认不依赖 Redis**，refresh token 使用内存存储，开箱即用。

如需使用 Redis（如测试生产行为），可按需安装：

### 5.1 安装 Memurai（推荐）

```powershell
winget install Memurai.Memurai

# 验证
redis-cli ping
# 输出: PONG
```

### 5.2 启用 Redis

在 `.env` 中取消注释：

```ini
REDIS_URL=redis://localhost:6379/0
```

### 5.3 安装 redis 驱动

```powershell
pip install redis
```

> **本地开发**：不配 Redis 也能正常启动，refresh token 自动使用内存存储。
> **生产环境**：建议配置 Redis + 安装 `redis` 包。

## 八、初始化种子数据

### 8.1 创建种子数据脚本

```powershell
# 确保 scripts 目录存在
New-Item -ItemType Directory -Force -Path scripts

# 创建 seed.py 文件
```

将以下内容保存为 `backend/scripts/seed.py`：

```python
"""
数据库种子数据初始化脚本
用法: python scripts/seed.py
"""
import asyncio

from sqlalchemy import select

from src.apps.users.models import User
from src.apps.users.services import hash_password
from src.apps.experthub.models import TagDefinition, ServiceDefinition
from src.core.database import async_session_factory


async def seed():
    print("🚀 开始初始化种子数据...")
    async with async_session_factory() as db:
        # 1. 创建管理员
        stmt = select(User).where(User.username == "admin")
        result = await db.execute(stmt)
        admin = result.scalar_one_or_none()
        if not admin:
            admin = User(
                username="admin",
                email="admin@example.com",
                password_hash=hash_password("admin123"),
                nickname="系统管理员",
                role="admin",
                status="active",
            )
            db.add(admin)
            print("✅ 管理员用户创建成功 (admin / admin123)")
        else:
            print("ℹ️  管理员用户已存在")

        # 2. 创建默认标签
        default_tags = [
            {"name": "AI/人工智能", "slug": "ai", "sort_order": 1},
            {"name": "大数据", "slug": "big-data", "sort_order": 2},
            {"name": "云计算", "slug": "cloud", "sort_order": 3},
            {"name": "前端开发", "slug": "frontend", "sort_order": 4},
            {"name": "后端开发", "slug": "backend", "sort_order": 5},
            {"name": "产品设计", "slug": "product-design", "sort_order": 6},
        ]
        for tag_data in default_tags:
            s = select(TagDefinition).where(TagDefinition.slug == tag_data["slug"])
            r = await db.execute(s)
            if not r.scalar_one_or_none():
                tag = TagDefinition(**tag_data)
                db.add(tag)
                print(f"✅ 标签创建成功: {tag_data['name']}")

        # 3. 创建默认服务形式
        default_services = [
            {"name": "技术咨询", "slug": "consulting", "sort_order": 1},
            {"name": "项目外包", "slug": "outsourcing", "sort_order": 2},
            {"name": "培训/讲师", "slug": "training", "sort_order": 3},
        ]
        for svc_data in default_services:
            s = select(ServiceDefinition).where(ServiceDefinition.slug == svc_data["slug"])
            r = await db.execute(s)
            if not r.scalar_one_or_none():
                svc = ServiceDefinition(**svc_data)
                db.add(svc)
                print(f"✅ 服务形式创建成功: {svc_data['name']}")

        await db.commit()

    print("\n🎉 种子数据初始化完成！")
    print("管理员账号: admin / admin123")
    print("请在首次登录后立即修改密码！")


if __name__ == "__main__":
    asyncio.run(seed())
```

### 8.2 运行种子数据脚本

```powershell
# 确保虚拟环境已激活
.\venv\Scripts\Activate.ps1

# 运行种子脚本
python scripts/seed.py

# 预期输出:
# 🚀 开始初始化种子数据...
# ✅ 管理员用户创建成功 (admin / admin123)
# ✅ 标签创建成功: AI/人工智能
# ...
# 🎉 种子数据初始化完成！
```

## 九、启动开发服务器

### 9.1 一键启动（使用 main.py 的 lifespan）


### 9.2 启动参数说明

```powershell
# 带更多参数的启动方式
uvicorn main:app `
  --reload `           # 热重载，代码修改后自动重启
  --host 0.0.0.0 `    # 监听所有网卡（局域网可访问）
  --port 8000 `        # 端口
  --log-level info `   # 日志级别
  --access-log `       # 启用访问日志
  --workers 1          # 开发模式用 1 个 worker
```

## 十二、常见问题排查

### 12.1 虚拟环境激活失败

```powershell
# 错误: 无法加载文件...因为在此系统上禁止运行脚本
# 解决方法：以管理员身份运行 PowerShell，执行：
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
# 然后重新激活
```

### 12.2 数据库连接失败

```powershell
# 如果使用 SQLite（默认）
# 检查 myweb.db 文件是否已生成
Test-Path myweb.db
# 输出: True

# 如果使用 PostgreSQL
Get-Service postgresql-x64-15
Start-Service postgresql-x64-15
netstat -ano | findstr :5432
psql -U postgres -d myweb -c "SELECT 1;"
```

### 12.3 Redis 连接失败

```powershell
# 本地开发默认不使用 Redis，此错误不影响启动
# 如果确实需要使用 Redis：
# 1. 安装 Memurai: winget install Memurai.Memurai
# 2. 在 .env 中取消 REDIS_URL 注释
# 3. 安装 redis 包: pip install redis
```

### 12.4 端口被占用

```powershell
# 检查 8000 端口占用
netstat -ano | findstr :8000

# 找到 PID 后终止进程
taskkill /PID <PID> /F

# 或者更换端口启动
uvicorn main:app --reload --port 8001
```

### 12.5 依赖安装失败

```powershell
# 尝试先单独安装关键依赖
pip install fastapi uvicorn sqlalchemy asyncpg

# 如果仍有问题，更新 pip
pip install --upgrade pip setuptools wheel

# 再次重试
pip install -e ".[dev]"
```

### 12.6 数据库迁移冲突

```powershell
# 如果你是首次初始化，可以直接重置：
alembic downgrade base
alembic upgrade head

# 或者手动删除 versions 目录下的文件，重新生成：
Remove-Item alembic/versions/* -Force
alembic revision --autogenerate -m "initial_migration"
alembic upgrade head
```

### 12.7 SQLite 数据库文件在哪

```powershell
# SQLite 数据库文件在项目根目录
Get-ChildItem E:\web\myweb\backend\myweb.db

# 如需重置数据库，删除文件后重新迁移即可
Remove-Item E:\web\myweb\backend\myweb.db
alembic upgrade head
```
